03 / ANTES DE GUARDAR

Revisa cómo quedará tu lista

Avanzado: documentos y formato técnico de entidades

Para flujos existentes. Si sólo quieres agregar nombres, usa las opciones anteriores.

Documentos sin conexión

JSONL: un objeto por línea con url,title,text,source_kind,published_at. Puede incluir entity_ids; si lo omites, el índice busca nombres completos y alias.

Entidades en formato técnico

CSV id,name,kind,aliases o JSONL. Tipos: person, company, organization. Este formato conserva el flujo de importación anterior.

Para listas mayores de 16 MB o 10,000 filas, divide el contenido en archivos más pequeños.
