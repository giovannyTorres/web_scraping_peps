Prepara tu cobertura

Habilita al menos una fuente y confirma sus condiciones de uso. Descargar el cuerpo de una noticia requiere un permiso adicional.

Sin fuentes preparadas

Autoriza la búsqueda API de Lumy / Yandex y la lectura de originales públicos para uso personal local. Puedes desmarcar cada permiso por separado; preparar no inicia la búsqueda.

Qué buscar y desde cuándo

Empieza por el nombre de cada persona o empresa. Puedes añadir contexto para distinguir homónimos; los índices de medios y feeds son complementarios.
